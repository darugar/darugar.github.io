Machine Learning vs AI - What's the Difference?

Sat 18 February 2023

A surprisingly common question I get is: what is AI? And what's machine learning? How do they differ? Which one do I use?

The Short Version

Machine learning is the term used by people who build and use the systems, AI is the term used by the media and casuals. If you want to sound like you know what you're talking about just say machine learning.

The Slightly More Intelligent Version

Let's talk about data science, machine learning, and AI.

All three start with data - they attempt to extract information from data, or use data to build systems: a recommender, a classifier, an image generator, a language model, etc.

Some broad generalizations:

Data science is humans using data to create systems. It generally involves a careful examination of the data in order to gain an understanding and draw insights, and application of statistical techniques to create useful systems based on the data. The intelligence is coming from humans - they figure out how to build systems that make use of the data to deliver value. Most of the "AI" you see in the world is actually just data science.

Machine Learning is when machines learn. Let's assume we agree on what machines are - what does "learn" mean?

Say we're going to build a machine to play tic-tac-toe. The normal way to do this would be to write a set of rules: in this situation, do this. We, the humans, supply the intelligence and the rules for accomplishing the task.

Machine learning is the process of getting the machines to learn the rules and heuristics by themselves. Humans aren't supplying the rules - the machines are learning them.

The most successful approach for this has been neural networks. Andrej Karpathy's The Spelled Out Intro to Neural Networks is an excellent technical overview - watch this if you really want to understand what's going on. If you're just looking for a high level description read my A Completely Non-Technical Explanation of AI and Deep Learning.
